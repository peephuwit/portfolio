ROOMRESERVE

Resource & meeting room scheduling platform

Overview

A modular resource scheduling engine with real-time conflict detection, showcased through an enterprise room booking interface.

Key Highlights

  • ▹
    Intelligent Conflict Detection: Server-side mathematical time-overlap algorithm prevents double bookings in real time (HTTP 409 Conflict).
  • ▹
    End-to-End Type Safety: Strict TypeScript interfaces and Zod validation enforce reliable data contracts across frontend and backend.
  • ▹
    Relational Modeling & Prisma ORM: Structured database schemas (Users, Rooms, Bookings) with SQLite persistence and Role-Based Access Control (RBAC).
  • ▹
    Interactive Timeline & Bilingual UX: Real-time schedule timeline view with instant Thai/English switching and automated Buddhist/Gregorian year conversion.
  • ▹
    Extensible Architecture: Data models and APIs designed to be adaptable for hot-desking, equipment, or appointment booking.
